Project Overview

Chewr is an AI-powered food recommendation application designed to make everyday meal decisions easier.

The application uses user preferences, dietary requirements and lifestyle information to provide more personalized meal recommendations.

Instead of browsing through countless food options, users can receive recommendations that are better suited to their individual needs.

My responsibilities included Flutter development, UI implementation, backend API integration, Firebase integration and AI-powered recommendation functionality.
