Project Overview

Inner Compass is a meditation and mindfulness application designed to provide users with a peaceful digital environment for relaxation and self-care.

The application provides relaxing music, calming sounds and guided sessions that help users focus, relax, sleep and create healthier mindfulness habits.

The experience was designed around simplicity and calmness, allowing users to easily discover suitable sessions and audio content.

My responsibilities included Flutter UI development, audio experience implementation, API integration, Firebase integration, subscription functionality and mobile application deployment.
