Project Overview

BackToLife Feed is a privacy-focused mobile application created to help users take better control over their social media experience.

The application focuses on reducing unwanted and distracting content by allowing users to control specific features of platforms such as YouTube, Instagram and Twitter.

The goal was to create a simple and modern interface where users can manage their digital environment without making the experience complicated.

My responsibilities included Flutter development, UI implementation, application logic, API integration, Firebase integration and overall mobile application development.
